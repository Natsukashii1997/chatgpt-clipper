# Claude Code 开工指令｜ReplyCanvas

请在新的项目目录中读取本交付包的 `ChatGPT高保真可编辑导出器_PRD_v1.0.md` 作为唯一产品需求基线，参考 `assets/reference_chatgpt.png` 的视觉样例。

你的角色：本项目主开发工程师。开发目标不是截图保存，而是让 ChatGPT 回答的文字、卡片、容器、箭头和受支持的图表对象被独立选中编辑，并在断网状态保持高保真视觉。

## 工作顺序

1. 首先评估 MV3 的权限、安全边界、DOM/ComputedStyle 捕获与离线资源固化；提交架构模块、数据模型、测试方案。
2. 实际完成 M0 技术验证：ChatGPT 网页单条回答选择 → 节点/样式捕获 → 离线 HTML → 文本与卡片可编辑 → 同尺寸原图视觉对比。
3. 对实际发现的限制提供证据，不得使用整张截图冒充可编辑导出。
4. M0 通过后继续开发 M1 完整闭环，再进入 M2 的图表语义编辑与 Figma 扩展。
5. 每个批次都运行真实测试，附上测试命令、输出、截图对比、文件路径、提交 SHA、未通过项。

## 项目必须提供

- Chrome 可加载的 `dist/` 构建
- 源代码、README、Manifest V3 最小权限说明
- 自动测试和真实 Chrome E2E
- 用户参考样例的原图、重建图、差异报告和可编辑 ZIP
- 编辑能力分级（E3/E2/E1/E0）的可视化说明
- 离线保存、再次导入和继续编辑的验证证据

不得宣称尚未验证的内容已完成，不得未经用户授权上传对话内容或绕过站点安全边界。若某验收项无法实现，应明确标记为技术阻塞并提交替代方案；不能静默降低验收标准。
