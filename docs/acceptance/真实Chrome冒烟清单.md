# 真实 Chrome 冒烟清单

自动测试全跑在替身上（无头 Chromium + 编的测试页、内存假文件系统）。到 2026-11-20 的四次线上事故（L-06、L-14、L-25、L-26）都只在常浩的真实 Chrome 里出现，测试里复现不出。这一页是合并后在真实 Chrome 里必走的一遍固定检查，补上替身够不到的地方。

## 什么时候走

| 合并的改动碰到了 | 走哪几项 |
|---|---|
| 写 Vault、文件夹授权、`src/lib/vault/` | S0–S4、S6、S8 |
| 页面适配 `adapter.ts`、转 Markdown、快照 | S0–S2、S4–S6 |
| 内容脚本、后台、消息、限时 | 全部 |
| 导出 PDF | S0、S7 |
| 表里没列的源码（如 `persist.ts`、`ui.ts`、`jump.ts`、设置页） | 全部 |
| 只改文档、测试 | 不用走 |
| Chrome 升级后第一次用（不是合并触发） | S0、S1、S8 |

拿不准就全走一遍，约 10 分钟。

## 前提

1. 主目录已拉齐到 main、`npm run build` 过；常浩在 `chrome://extensions` 点过本插件的刷新按钮。
2. 设置页已选好 Vault 文件夹、填了 Obsidian 位置。
3. 样本对话：ChatGPT、Claude 各一个常浩同意拿来测的对话，ChatGPT 那个至少两问两答、有一条带图片的回答。写交接时只写代号，不写对话内容。
4. 剪贴板里别放要用的东西（单条收藏会把长图放进剪贴板）。

## 清单

谁做：「Claude」是 Claude in Chrome 能做的；「常浩」是要他亲手做的（重启浏览器、扩展页按钮、系统弹窗）。

| 编号 | 检查什么 | 怎么做 | 应该看到 | 谁做 |
|---|---|---|---|---|
| S0 | 浏览器里跑的是新版 | 设置页点「自检」；或在对话页发 `clipper-diag` 事件 | 打包时间是这次构建的时间；设置页和后台是同一版；七步全通 | Claude |
| S1 | 单条收藏（ChatGPT，带图片的回答） | 点丝带 | 四步全绿，「PNG 文件」写「已复制」；Vault 里新文件夹有 `answer.png` 和笔记；打开长图看一眼图在 | Claude |
| S2 | 同一条再收 | 再点一次丝带 | 「已更新」，Vault 里还是那一个文件夹，没有「(2)」 | Claude |
| S3 | 节选 | 在一条回答里选中两段文字，点变成荧光笔的丝带 | 丝带写「收藏选中·2块」；新文件夹名带「（节选）」；笔记只有那两段 | Claude |
| S4 | 整段收藏（ChatGPT） | 按住丝带往下拉过约 100px 松手 | 页面从头滚到尾再滚回原位；文件夹名带「（整段）」，每条回答一张 `answer-NN.png`，笔记按轮排 | Claude |
| S5 | Claude 单条和整段 | 在 Claude 样本对话里做 S1、S4 | 笔记 `source: claude`；不含思考过程行和按钮；整段不漏条 | Claude |
| S6 | 跳回原回答、在 Obsidian 里打开 | 点进度卡绿块；在 Obsidian 里点笔记顶部「↩ 打开原回答」 | Obsidian 打开这篇笔记；浏览器打开对话、滚到那条回答、开头闪一抹淡黄 | 常浩（Obsidian 和系统弹窗） |
| S7 | 导出 PDF | 收藏完点进度卡「导出 PDF」 | 「已存到「下载」· N 页」；PDF 里图、表格、公式都在 | Claude 点，常浩看 PDF 效果 |
| S8 | 插件刷新、Chrome 重启之后 | ① 扩展页点刷新，不刷新对话页（要是刚用过、没休眠的标签页；休眠的补装不上，会提醒刷新，不算不通过），直接点丝带收藏；② 完全退出 Chrome 再打开，收藏一条 | ① 能收，不提醒刷新；② 能收；卡住的话几秒内写明原因并退回下载，不会一直转圈（L-25、L-26） | 常浩操作，Claude 看结果 |
